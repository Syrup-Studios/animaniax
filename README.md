# Animaniax

Animaniax is an animal overhaul mod for Minecraft, heavily inspired by [Animania](https://github.com/capnkirok/animaniamod). It is built with original code and supports Minecraft 1.21.1 on Fabric and NeoForge.

Animaniax currently uses textures, models, and sounds from Animania as placeholders. We plan to replace them with our own textures, models, and sounds soon. See the [third-party asset notice](LICENSES/ANIMANIA_ASSETS_NOTICE.md) for attribution and license details.
