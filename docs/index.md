# Animaniax

Animaniax is an animal overhaul mod for Minecraft 1.21.1, inspired by Animania and built with original code for Fabric and NeoForge.

It adds named animal breeds, daily care and sleep routines, pregnancy and offspring growth, breed-specific milk, cheese, and wool, prime meats, companion pets, frogs and toads, and animal-drawn farm transport.

## What you need

Install Animaniax and its required dependencies on both your game client and server.

| Requirement | Version |
| --- | --- |
| Minecraft | `1.21.1` |
| Java | `21` or newer |
| Mod Loader | Fabric Loader `>= 0.20.1` with Fabric API `>= 0.116.18+1.21.1`, or NeoForge `>= 21.1.265` |
| Required Mod | Syrup Library `>= 0.6.0` |
